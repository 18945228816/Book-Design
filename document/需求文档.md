# 读书感悟记录系统 - 需求文档

## 1. 背景与痛点

- 读完书后内心有感悟，但难以清晰表达
- 时间久了会遗忘书中的精华内容
- 读书的目标是**出口成章**——能把书中的智慧用口语化的方式表达出来

## 2. 系统定位

**轻量记录 + AI引导表达**

用户不在系统上读书，而是在读完书后，把感悟记录下来，AI帮助用户把模糊的感受转化为清晰、口语化的表达素材。

## 2.1 技术选型

| 层级 | 技术栈 | 说明 |
|------|--------|------|
| **前端** | Vue 3 + Vite + Element Plus | 组件化开发，UI组件库 |
| **后端** | Python + FastAPI | 高性能异步框架，AI生态好 |
| **数据库** | MySQL（本地） | 先本地开发，后续可迁移云端 |
| **文件存储** | 本地存储 | 书籍文件、导出文件 |

## 3. 核心功能

### 3.1 书籍管理
- 上传书籍内容（支持 txt/pdf/epub）
- 按书籍分类管理
- **整体概览**：上传后AI自动提炼全书精华，生成核心观点摘要，帮助快速定位值得记录的部分

### 3.2 AI引导记录
- 用户选择书中段落，或输入模糊的感悟关键词
- AI通过提问引导用户表达：
  - "你说的震撼是指什么？"
  - "这让你联想到了什么经历？"
- AI帮助用户把感悟转化为**口语化表达**
- 生成"说话版本"的精华总结（而非书面文字）

### 3.3 素材库
- 保存口语化金句（可直接说出来用）
- **标签系统**：自定义标签（如：人生观、方法论、情感、职场...），支持多标签分类
- **多书关联**：不同书之间相似/互补的观点自动关联或手动建立联系
- 快速搜索检索（按关键词、标签、书籍筛选）

### 3.4 快速录入
- 提供快捷入口（如：浏览器插件、手机端快捷方式）
- 支持语音输入，AI自动整理成文字
- 极简界面：输入关键词/短语 → 保存，稍后再完善

### 3.5 导出
- 支持导出为 Markdown/Word/PDF 格式
- 可按书籍、标签、时间范围筛选导出
- 导出内容包含：口语化表达 + 原文对照 + 标签

### 3.6 表达练习（可选）
- AI给出话题，用户尝试表达
- AI对比用户表达和已有素材，给出优化建议

## 4. 用户流程

```
上传书籍 → AI生成全书概览 → 阅读时有感悟
    → 快速录入（语音/文字/图片）→ 选择段落/输入感受
    → AI提问引导 → AI生成口语化表达 → 添加标签
    → 保存到素材库 → 需要时搜索/导出调用
```

**快速录入场景：**
```
突然有灵感 → 打开快捷入口 → 输入关键词/语音 → 保存
    → 稍后有时间时 → 完善成完整的口语化表达
```

## 5. 设计原则

| 原则 | 说明 |
|------|------|
| **轻量** | 单次使用不超过5-10分钟 |
| **引导式** | AI主动提问，帮用户理清思路 |
| **口语化** | 输出是"能说的话"，不是"能写的文字" |
| **可检索** | 按话题/关键词快速找到相关内容 |

## 6. 不包含的功能

- 在线阅读功能（用户在外部读书）
- 复杂的复习/背诵系统（用户不想花太多时间）
- 社交/分享功能
