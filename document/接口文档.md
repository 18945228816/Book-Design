# 读书感悟记录系统 - 接口文档

## 1. 接口规范

### 1.1 基础信息
- **Base URL**: `/api/v1`
- **协议**: HTTPS
- **数据格式**: JSON
- **字符编码**: UTF-8

### 1.2 认证方式
- **类型**: JWT (JSON Web Token)
- **Header**: `Authorization: Bearer <token>`
- **Token有效期**: 7天
- **刷新机制**: Token过期后需重新登录

### 1.3 通用响应格式

**成功响应**
```json
{
  "code": 200,
  "message": "success",
  "data": { ... }
}
```

**错误响应**
```json
{
  "code": 400,
  "message": "错误描述",
  "data": null
}
```

### 1.4 状态码说明
| 状态码 | 说明 |
|--------|------|
| 200 | 成功 |
| 201 | 创建成功 |
| 400 | 请求参数错误 |
| 401 | 未认证 |
| 403 | 无权限 |
| 404 | 资源不存在 |
| 500 | 服务器内部错误 |

## 3. 书籍模块

### 3.1 上传书籍
```
POST /api/v1/books
Content-Type: multipart/form-data
```

**请求参数**
| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| file | File | 是 | 书籍文件（txt/pdf/epub）|
| title | String | 否 | 书名（不传则从文件解析）|
| author | String | 否 | 作者 |

**响应**
```json
{
  "code": 201,
  "message": "上传成功",
  "data": {
    "book_id": "uuid",
    "title": "书名",
    "author": "作者",
    "file_type": "pdf",
    "chapters_count": 12,
    "created_at": "2026-04-27T10:00:00Z"
  }
}
```

### 3.2 获取书籍列表
```
GET /api/v1/books
```

**查询参数**
| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| page | Int | 否 | 页码，默认1 |
| page_size | Int | 否 | 每页数量，默认20 |
| sort | String | 否 | 排序：created_at/title |

**响应**
```json
{
  "code": 200,
  "message": "success",
  "data": {
    "total": 10,
    "page": 1,
    "page_size": 20,
    "items": [
      {
        "book_id": "uuid",
        "title": "书名",
        "author": "作者",
        "materials_count": 5,
        "created_at": "2026-04-27T10:00:00Z"
      }
    ]
  }
}
```

### 3.3 获取书籍详情
```
GET /api/v1/books/{book_id}
```

**响应**
```json
{
  "code": 200,
  "message": "success",
  "data": {
    "book_id": "uuid",
    "title": "书名",
    "author": "作者",
    "file_type": "pdf",
    "chapters": [
      {
        "chapter_id": "uuid",
        "title": "第1章",
        "order": 1
      }
    ],
    "overview": "AI生成的整体概览...",
    "materials_count": 5,
    "created_at": "2026-04-27T10:00:00Z"
  }
}
```

### 3.4 生成整体概览
```
POST /api/v1/books/{book_id}/overview
```

**响应**
```json
{
  "code": 200,
  "message": "success",
  "data": {
    "overview": "AI生成的整体概览内容...",
    "key_points": ["观点1", "观点2", "观点3"],
    "suggested_tags": ["人生观", "认知"]
  }
}
```

### 3.5 删除书籍
```
DELETE /api/v1/books/{book_id}
```

```json
}
```

**响应**
```json
{
  "code": 201,
  "message": "success",
  "data": {
    "conversation_id": "uuid",
    "messages": [
      {
        "role": "ai",
```
