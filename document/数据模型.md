# 读书感悟记录系统 - 数据模型

## 1. 数据库选型

- **主数据库**: MySQL 8.0+（本地部署）
- **缓存**: Redis（可选，后期优化时引入）
- **文件存储**: 本地文件系统（后期可迁移OSS/S3）

## 3. 数据表详细设计

### 3.1 users 表（用户表）

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| user_id | UUID | PK | 用户唯一标识 |
| email | VARCHAR(255) | UNIQUE, NOT NULL | 邮箱 |
| username | VARCHAR(100) | NOT NULL | 用户昵称 |
| password_hash | VARCHAR(255) | NOT NULL | 密码哈希 |
| avatar_url | VARCHAR(500) | | 头像URL |
| created_at | TIMESTAMP | NOT NULL | 创建时间 |
| updated_at | TIMESTAMP | NOT NULL | 更新时间 |

**索引**
- `idx_users_email` - email唯一索引

### 3.2 books 表（书籍表）

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| book_id | UUID | PK | 书籍唯一标识 |
| user_id | UUID | FK → users | 所属用户 |
| title | VARCHAR(500) | NOT NULL | 书名 |
| author | VARCHAR(200) | | 作者 |
| file_type | VARCHAR(10) | NOT NULL | 文件类型：txt/pdf/epub |
| file_url | VARCHAR(500) | | 文件存储路径 |
| overview | TEXT | | AI生成的整体概览 |
| created_at | TIMESTAMP | NOT NULL | 创建时间 |
| updated_at | TIMESTAMP | NOT NULL | 更新时间 |

**索引**
- `idx_books_user_id` - user_id索引
- `idx_books_created_at` - created_at索引

### 3.3 chapters 表（章节表）

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| chapter_id | UUID | PK | 章节唯一标识 |
| book_id | UUID | FK → books | 所属书籍 |
| title | VARCHAR(500) | | 章节标题 |
| content | TEXT | | 章节内容 |
| chapter_order | INT | NOT NULL | 章节顺序 |
| created_at | TIMESTAMP | NOT NULL | 创建时间 |

**索引**
- `idx_chapters_book_id` - book_id索引
- `idx_chapters_order` - (book_id, chapter_order)复合索引

### 3.4 materials 表（素材表）

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| material_id | UUID | PK | 素材唯一标识 |
| user_id | UUID | FK → users | 所属用户 |
| book_id | UUID | FK → books | 关联书籍（可选）|
| chapter_id | UUID | FK → chapters | 关联章节（可选）|
| content | TEXT | NOT NULL | 口语化表达内容 |
| original_text | TEXT | | 原文段落 |
| status | VARCHAR(20) | NOT NULL | 状态：draft/completed |
| created_at | TIMESTAMP | NOT NULL | 创建时间 |
| updated_at | TIMESTAMP | NOT NULL | 更新时间 |

**索引**
- `idx_materials_user_id` - user_id索引
- `idx_materials_book_id` - book_id索引
- `idx_materials_status` - status索引
- `idx_materials_created_at` - created_at索引
- `idx_materials_content_fts` - content全文索引

### 3.5 tags 表（标签表）

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| tag_id | UUID | PK | 标签唯一标识 |
| user_id | UUID | FK → users | 所属用户 |
| name | VARCHAR(100) | NOT NULL | 标签名称 |
| is_system | BOOLEAN | DEFAULT false | 是否系统预设 |
| created_at | TIMESTAMP | NOT NULL | 创建时间 |

**索引**
- `idx_tags_user_id` - user_id索引
- `idx_tags_name` - (user_id, name)唯一索引

### 3.6 material_tags 表（素材标签关联表）

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| material_id | UUID | FK → materials | 素材ID |
| tag_id | UUID | FK → tags | 标签ID |

**主键**: (material_id, tag_id)
**索引**
- `idx_material_tags_tag_id` - tag_id索引

### 3.7 material_relations 表（素材关联表）

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | UUID | PK | 关联记录ID |
| material_id | UUID | FK → materials | 素材ID |
| related_material_id | UUID | FK → materials | 关联素材ID |
| relation_type | VARCHAR(20) | NOT NULL | 关联类型：similar/complementary/opposite |
| created_at | TIMESTAMP | NOT NULL | 创建时间 |

**索引**
- `idx_material_relations_material_id` - material_id索引
- `idx_material_relations_related_id` - related_material_id索引

### 3.8 conversations 表（对话会话表）

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| conversation_id | UUID | PK | 对话唯一标识 |
| user_id | UUID | FK → users | 所属用户 |
| book_id | UUID | FK → books | 关联书籍（可选）|
| chapter_id | UUID | FK → chapters | 关联章节（可选）|
| created_at | TIMESTAMP | NOT NULL | 创建时间 |

**索引**
- `idx_conversations_user_id` - user_id索引

### 3.9 messages 表（消息表）

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| message_id | UUID | PK | 消息唯一标识 |
| conversation_id | UUID | FK → conversations | 所属对话 |
| role | VARCHAR(10) | NOT NULL | 角色：user/ai |
| content | TEXT | NOT NULL | 消息内容 |
| metadata | JSON | | 附加数据（AI建议等）|
| created_at | TIMESTAMP | NOT NULL | 创建时间 |

**索引**
- `idx_messages_conversation_id` - conversation_id索引
- `idx_messages_created_at` - created_at索引

## 4. 数据关系说明

### 4.1 核心关系
- **用户 → 书籍**: 一对多（一个用户可以上传多本书）
- **书籍 → 章节**: 一对多（一本书有多个章节）
- **用户 → 素材**: 一对多（一个用户可以创建多个素材）
- **书籍 → 素材**: 一对多（一本书可以关联多个素材）
- **素材 → 标签**: 多对多（通过material_tags关联）

### 4.2 可选关系
- **素材 ↔ 素材**: 多对多（通过material_relations关联）
- **对话 → 书籍**: 多对一（对话可以关联到某本书）

## 6. 性能优化建议

### 6.1 索引优化
- 高频查询字段建立索引
- 复合查询使用复合索引
- 全文搜索使用MySQL FULLTEXT索引（InnoDB支持）

### 6.2 查询优化
- 分页查询使用LIMIT/OFFSET（数据量大时考虑游标分页）
- 避免N+1查询，使用JOIN或批量查询
- 合理使用MySQL查询缓存

### 6.3 数据归档
- 定期归档历史对话数据
- 软删除标记而非物理删除
- 大表考虑分区（按时间）
