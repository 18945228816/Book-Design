## 3. 交互流程

### 3.1 完整记录流程

```
用户上传书籍
    ↓
AI生成整体概览（可选）
    ↓
用户阅读书籍（外部阅读）
    ↓
有感悟时打开系统
    ↓
选择：
├── 快速录入 → 输入关键词/语音 → 保存草稿
│       ↓
│   稍后完善
│       ↓
└── AI对话引导 → 选择相关段落
        ↓
    AI提问："你说的XX是指什么？"
        ↓
    用户回答
        ↓
    AI生成口语化表达
        ↓
    用户确认/修改
        ↓
    添加标签
        ↓
    保存到素材库
```

### 3.2 快速录入流程

```
用户触发快速录入（快捷键/入口）
    ↓
极简界面弹出
    ↓
用户输入：
├── 文字：关键词/短语
├── 图片：上传书籍图片 → AI描述
└── 语音：录音 → AI转文字
    ↓
保存为草稿（待完善状态）
    ↓
可选：立即进入AI对话完善
```

### 3.3 搜索检索流程

```
用户打开素材库
    ↓
输入搜索条件：
├── 关键词
├── 标签筛选
├── 书籍筛选
└── 时间范围
    ↓
显示匹配结果
    ↓
点击查看详情
    ↓
可选：导出 / 编辑 / 关联
```

### 3.4 导出流程

```
用户进入导出页面
    ↓
选择导出范围：
├── 全部素材
├── 按书籍筛选
├── 按标签筛选
└── 按时间筛选
    ↓
选择导出格式：
├── Markdown
├── Word
└── PDF
    ↓
预览导出内容
    ↓
确认导出 → 下载文件
```

## 4. 功能详细说明

### 4.1 书籍管理

#### 4.1.1 上传书籍
- **支持格式**：txt、pdf、epub
- **文件大小限制**：50MB
- **处理逻辑**：
  - 解析文件内容
  - 提取章节结构（如可识别）
  - 存储原文内容

#### 4.1.2 整体概览
- **触发方式**：上传后自动生成 / 手动触发
- **生成内容**：
  - 全书核心观点（3-5个）
  - 值得记录的亮点段落推荐
  - 书籍主题标签建议
- **可编辑**：用户可修改AI生成的概览

### 4.2 AI引导记录

#### 4.2.1 对话引导
- **输入方式**：
  - 选择书中段落
  - 输入模糊感受（如"震撼"、"孤独"）
- **AI提问策略**：
  - 追问具体细节："你说的XX是指什么？"
  - 引导联想："这让你想到了什么经历？"
  - 深化理解："你同意这个观点吗？为什么？"

#### 4.2.2 口语化转换
- **转换规则**：
  - 书面语 → 日常说话风格
  - 长句 → 短句
  - 复杂词汇 → 简单词汇
- **输出格式**：
  - 口语化表达（主要）
  - 原文对照（参考）

### 4.3 素材库

#### 4.3.1 素材结构
```
{
  "id": "唯一标识",
  "content": "口语化表达内容",
  "original_text": "原文段落（可选）",
  "book_id": "关联书籍",
  "tags": ["标签1", "标签2"],
  "related_materials": ["关联素材ID"],
  "status": "draft/completed",
  "created_at": "创建时间",
  "updated_at": "更新时间"
}
```

#### 4.3.2 标签系统
- **标签类型**：
  - 系统预设：人生观、方法论、情感、职场、认知...
  - 用户自定义
- **标签操作**：
  - 创建、编辑、删除
  - 合并相似标签
  - 按使用频率排序

#### 4.3.3 多书关联
- **关联方式**：
  - 手动关联：用户选择相关素材
  - 自动推荐：AI识别相似观点
- **关联类型**：
  - 相似观点
  - 互补观点
  - 对立观点

### 4.4 快速录入

#### 4.4.1 快捷入口
- **触发方式**：
  - 浏览器插件
  - 快捷键（Ctrl+Shift+K）
  - 手机端小组件
- **界面**：极简浮窗

#### 4.4.2 语音输入
- **流程**：录音 → 语音识别 → 文字 → AI整理
- **支持语言**：中文

### 4.5 导出

#### 4.5.1 导出格式
| 格式 | 说明 |
|------|------|
| Markdown | 适合笔记软件导入 |
| Word | 适合打印分享 |
| PDF | 适合归档 |

#### 4.5.2 导出内容结构
```markdown
# 素材库导出
导出时间：2026-04-27
筛选条件：《书名》

---

## 素材1
**口语化表达**：xxxxx

**原文**：xxxxx

**标签**：人生观、认知

**关联素材**：素材2、素材5

---
```
